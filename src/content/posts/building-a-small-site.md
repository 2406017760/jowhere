个人网站最重要的不是技术有多复杂，而是它是否能让你愿意持续更新。

我喜欢静态站点的原因很简单：文章是普通的 Markdown 文件，所有内容都在自己的 Git 仓库里。没有数据库升级，没有服务器补丁，写完提交就会发布。

## 一条简单的路线

1. 注册一个自己喜欢的域名。
2. 用 Astro 生成博客。
3. 把网站连接到 Cloudflare Pages。
4. 写下第一篇文章。

剩下的事情，就交给时间。
